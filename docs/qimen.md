
# 九星与九宫

## 坎一宫 天蓬星
五行属水,阳性,古人把它规定为凶星,因为它胆大妄为,又喜欢暗中行事,故作为杀人犯,抢劫犯,大盗,大贪污犯的代表符号.在预测刑事案件的过程中,都以天蓬星作为凶犯的用神,这是其主要特征.但凶吉是相对的.比如镇守边关的大将,投机做大生意的巨商,敢冒风险,具有大智慧的人往往也临着天蓬星,因为天蓬星属水,水主智.总之,聪明,胆大,喜欢暗中行事,这是它的主要特点.

## 坤二宫 天芮星
五行属土,阴性,古人规定它为凶星,因为它有阴险,贪毒的一面,与疾病有关,所以在预测疾病的过程中,它是代表疾病的主要符号.但它也有吉的一面,比如在测妇女孕产中它代表孕妇,在测职业的时候它代表农民,在测拜师学艺方面它代表学员等.同时它也具有坤宫的性质,比如代表母亲,妇女,大地,大众,下层民众,学生等.

## 震三宫 天冲星
五行属木,阳性,古人视其为吉星,因为它是在战场上敢打敢冲的武士,在工作中也具有雷厉风行,干事爽快利索的优点,但它也有冒失,粗鲁,不稳重的一面,故有人认为它是次吉星.

## 巽四宫 天辅星
五行属木,阳性,古人认为它是天上的文曲星,大吉之星.在奇门应用中,往往代表老师,班主任,考试院,文化程度等等.
